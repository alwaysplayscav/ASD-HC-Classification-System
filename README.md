# 模式识别教学作业：基于 T1 加权结构 MRI 的 ASD / HC 分类

## 一、作业背景

自闭症谱系障碍（Autism Spectrum Disorder, ASD）是一类神经发育障碍。
结构磁共振成像（structural MRI, sMRI）可以在活体上无创地度量脑灰质、
白质的形态学特征，是研究 ASD 脑结构改变的重要手段。

本作业要求你使用一个小规模的真实 T1 加权影像数据集，独立完成一个
**二分类模式识别**任务的完整流程：影像预处理 → 特征提取 → 特征选择 /
降维 → 分类器训练 → 测试集预测 → 性能评价。

## 二、数据来源与匿名化

- 数据来自 ABIDE（Autism Brain Imaging Data Exchange）公共数据集。
- 仅使用 **NYU 中心** 的受试者（原始 `SUB_ID` 以 `5` 开头）。
- 所有影像均为 T1 加权结构像（`*_T1w.nii.gz`，NIfTI 格式，gzip 压缩）。
- 为进行盲测，受试者已被**重新乱序编号**：原始编号与诊断信息均已去除，
  文件名中的编号（如 `sub-037`）是随机分配的匿名编号，与诊断、年龄、
  性别、原始编号均无对应关系，**不要试图从编号推断任何信息**。

### 影像参数

146 例影像已经过统一整理，格式一致，可直接读取：

| 属性 | 取值 |
|---|---|
| 格式 | NIfTI-1（`.nii.gz`，gzip 压缩） |
| 数据类型 | int16 |
| 图像尺寸 | 128 × 256 × 256 |
| 体素大小 | 1.33 × 1.0 × 1.0 mm |
| 模态 | T1 加权结构像 |

注意：这些影像是**原始空间（native space）**的，未配准到标准空间。
不同受试者的脑在图像中的位置、朝向和大小各不相同，因此
**直接按体素位置跨受试者比较是不可靠的**，必须先做配准与分割，
再在统一空间（如 MNI）中提取特征。

测试集的**真值标签不随本文件夹发放**，由教师单独保存用于评阅。
`test/` 中的 10 例为 **5 例 ASD + 5 例 HC**，但顺序已随机打乱，
你无法从编号或文件名判断任何一例的诊断。

`train_labels.csv` 格式：

| 列名 | 说明 |
|---|---|
| `subject_id` | 匿名编号，与 `train/` 中的文件名对应 |
| `label` | 诊断标签：**1 = ASD，2 = HC** |

例：`sub-003,1,ASD` 表示 `train/sub-003_T1w.nii.gz` 为 ASD 患者。

## 四、作业任务

1. **预处理**：对 T1 影像进行必要的预处理，例如
   头动/偏置场校正、配准到标准空间（MNI）、脑组织分割（灰质/白质/脑脊液）、
   空间平滑等。可以使用 SPM、FSL、ANTs、CAT12、nibabel 等工具。
2. **特征提取**：从每个受试者中提取一个特征向量。可行方案例如：
   - VBM 灰质密度图像素（或降采样后）作为特征；
   - 基于脑图谱（AAL、Harvard-Oxford 等）的 ROI 均值 / 体积作为特征；
   - 皮层厚度、表面积、曲率等形态学指标；
   - 也可以自行设计特征。
3. **特征选择 / 降维**：如 t 检验、卡方检验、LASSO、PCA 等。
4. **分类建模**：选择合适的分类器，例如 LDA、SVM、逻辑回归、
   随机森林、k-NN，或卷积神经网络。
5. **模型评估**：由于训练集样本量较小，建议使用**交叉验证**估计泛化性能；
   注意特征选择必须嵌套在交叉验证内部，否则会造成信息泄漏、性能虚高。
6. **测试集预测**：用最终模型对 `test/` 中 10 例给出预测标签。

## 五、提交要求

### 1. 预测结果文件 `submission.csv`

请以 `submission_example.csv` 为模板填写。该模板已经帮你写好了
`test/` 中全部 10 例的 `subject_id`，**`label` 列是空的，需要你填写**。
填完后另存为 `submission.csv`（保持两列、含表头、10 行）：

```csv
subject_id,label
sub-007,
sub-010,
...
```

填写后的样子（**下面两行的 `1` / `2` 只是演示格式，不是真实答案**）：

```csv
subject_id,label
sub-007,1
sub-010,2
```

要求：

- `label` 只能取 `1`（ASD）或 `2`（HC）；
- `subject_id` 必须与 `test/` 中的文件名一致（去掉 `_T1w.nii.gz` 后缀）；
- 10 行缺一不可，顺序不限。

### 2. 方法与结果报告（建议 3–6 页）

需包含：

- 完整的处理流程与关键参数；
- 特征维度、特征选择方法与分类器设置；
- 交叉验证的**准确率（ACC）、灵敏度（Sensitivity）、特异度（Specificity）**；
- 测试集预测结果；
- 对结果的分析与讨论（如样本量、类别不平衡、过拟合风险、
  预处理对结果的影响等）。

## 六、评分标准

| 项目 | 权重 | 说明 |
|---|---|---|
| 测试集预测准确率 | 40% | 10 例中预测正确的比例 |
| 流程完整性与正确性 | 30% | 是否避免了信息泄漏、是否合理使用交叉验证 |
| 报告质量 | 20% | 逻辑清晰、图表规范、讨论深入 |
| 创新性 | 10% | 特征设计、模型选择或分析角度有新意 |

## 七、提示与注意事项

- 训练集类别不平衡（ASD 与 HC 数量不等），评价时不要只看准确率，
  建议同时报告灵敏度和特异度，或使用 AUC。
- 小样本下测试集只有 10 例，**单次准确率的随机波动很大**
  （随机猜测的期望准确率约为 50%，但 95% 区间很宽），
  请勿过度解读测试集上的微小差异。
- 影像数据未经统一预处理，扫描参数、头动、颅内体积等都会影响结果，
  请思考如何控制这些混杂因素。
- 请勿使用任何外部信息（如通过网络检索原始 ABIDE 编号对应的诊断）
  来"作弊"完成预测；这既违反学术诚信，也违背本作业的训练目的。
